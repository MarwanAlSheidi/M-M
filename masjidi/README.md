# مسجدي — Masjidi

منصة لربط أئمة المساجد في سلطنة عُمان بالمتطوعين والشركات المعتمدة، لإدارة
أعمال الصيانة بشفافية. مبنية على Parse Server، ومهيّأة مسبقاً بـ **18,214
مسجداً** من البيانات المفتوحة لوزارة الأوقاف والشؤون الدينية.

> **للنشر اقرأ [`docs/DEPLOY.md`](./docs/DEPLOY.md) — وهو المرجع.** ما في هذا
> الملفّ تعريفٌ وبدءُ عملٍ محلّي، والدليل يشرح الترتيب وما يقع إن اختلّ.

## ما حاله اليوم

- ✅ **دوال السحابة والواجهة مكتملتان** ومُشغَّلتان على `parse-server` حقيقي.
- ✅ **الاختبارات:** `npm run verify` — خمس طبقات، **ويعدّ التخطّي سقوطاً**.
- ❌ **لم يُجرَّب على MongoDB بعد** (وهو ما يعمل عليه Back4app). كل اختباراتنا
  على PostgreSQL، و`npm run preflight` هو ما يقيس الفرق على قاعدةٍ حيّة.
- ⚠️ **مسار التبرعات مكتوبٌ ومعطَّل** — انظر «التنبيه» أدناه.

## البدء محلّياً — بلا خادمٍ ولا مفاتيح

```bash
npm install
npm test                  # اختبارات دوال السحابة على بديل Parse
npm run verify -- --quick # الفحص واختبارات الوحدة
```

والفحص الكامل يحتاج PostgreSQL وChromium، ويُشغّلهما بنفسه:

```bash
npm run verify            # الطبقات الخمس — ويسقط إن تُخطّيت واحدة
```

### نسخةٌ تُجرَّب بلا نشر

```bash
npm run demo              # صفحةٌ واحدة تحمل خادمَها — app/demo-dist/
```

الشاشاتُ نفسها فوق خادمٍ يعمل **داخل المتصفّح**، بثلاثة حسابات جاهزة و٤٩٥
مسجداً من بيانات الوزارة. تُفتح من ملفٍّ بلا شبكةٍ ولا خادم — للعرض على من
يسأل «أرِني». وحدودُها معلنة فيها: البيانات في ذاكرة الصفحة وتعود إلى حالها
مع كل إعادة تحميل، والمنطقُ الحقيقي في `cloud/` لا فيها.

## النشر — الخطوط العريضة

التفصيل وترتيبه في [`docs/DEPLOY.md`](./docs/DEPLOY.md). وهذه الخريطة وحدها:

```bash
cp .env.example .env                 # مفاتيح Back4app — أربعة أسطر
npm run deploy                       # المخطط ثم محافظةٌ واحدة رخيصة
# ثم الصق cloud/main.bundle.js في لوحة Cloud Code،
# وأضف فهرساً **فريداً** على Mosques.externalId من Database → Indexes
npm run admin -- --username <اسمه>   # أوّل مشرف — بدونه المنصّة معطّلة
npm run preflight                    # ← اللحظة الحاسمة: يقيس على قاعدتك الحيّة
```

و`npm run deploy` **يقف عند أوّل سقوط ويقول ما الذي لم يقم** — فلا يمضي إلى ما
بعد خطوةٍ لم تتمّ. وإعادتُه بلا ثمن: قِيس تشغيلُه مرّتين على خادمٍ حقيقي فبقيت
المساجد 264 لا 528 (`tests/integration/first-deploy.test.js`). وما يُنفَّذ
باليد في اللوحة **لا يقول عنه «تمّ»** — يُذكّر به ويترك `preflight` يكشفه.

ولاحقاً، بعد أشهر التشغيل:

```bash
npm run export                       # نسخةٌ من السجلّ قبل أن يحذفه التقليم
```

**و`npm run preflight` يبقى أحمر حتى تُنفَّذ الخطوات اليدوية** — وأهمُّها فهرسٌ
**فريد** على `Mosques.externalId` يُضاف من لوحة Back4app، فمخطط Parse لا يعبّر
عن التفرّد. أمّا الفهارس المكانية (`2dsphere`) فيطبّقها `npm run schema` على
MongoDB، والقرب يعمل بدونها على صندوق الإحاطة — **تحسينٌ لا شرط**.

والاستيراد الكامل **يُطلب باسمه** (`--all`): 18,214 سجلاً قد تُنفق ثلاثة أرباع
الباقة المجانية في عمليةٍ واحدة، ولا تُستردّ. السكربت يقول لك الكلفة ويدلّك على
البديل.

## الواجهة

```bash
cd app
cp .env.example .env      # VITE_PARSE_* — مفاتيح العميل، لا Master Key
npm install && npm run build
npm run verify:pwa        # يفحص التثبيت والعمل بلا إنترنت
```

انشر `app/dist` على أي استضافة ساكنة — **بـHTTPS**، فتحديد الموقع مرفوض
بدونها، وعليه يقوم «ما حولي» وترتيب الفرص بالمسافة.

## تنبيه

مسار التبرعات مكتوب لكنه **معطّل**. جمع التبرعات للمساجد في السلطنة يخضع
لوزارة الأوقاف والشؤون الدينية ويتطلب تصريحاً، وبوابة الدفع تتطلّب سجلاً
تجارياً وحساباً تاجراً. **المرحلة الأولى تُطلق بمسار التطوّع العيني وحده** —
وهذا قرارٌ تنظيمي لا نقصٌ في الكود.

## البيانات

مصدرها وزارة الأوقاف والشؤون الدينية (بيانات مفتوحة، 2025–2026). وما استُخرج
من **OpenStreetMap** يخضع لترخيص ODbL ويشترط النسبة — «© مساهمو
OpenStreetMap» معروضةٌ في شاشة «حسابي» ومكتوبةٌ في كل ملفٍّ يُخرجه السكربت،
**لا تحذفها**. تفاصيل التنظيف ومشاكل المصدر في [`docs/DATA.md`](./docs/DATA.md).

## الخطّ

الواجهة تحمل خطّها بنفسها: **IBM Plex Sans Arabic**، أربعة ملفّات في
`app/src/fonts/` (‏١٢٥ كيلوبايت: المقطعان العربيّ واللاتينيّ بوزنين). **ولا
يُجلب من خوادم Google Fonts** — التطبيق يعمل بلا إنترنت، ورابطٌ خارجيّ يكسر
ذلك ويُسرّب زوّار المنصّة إلى طرفٍ ثالث. ويحرس تخزينَه المسبق
`npm run verify:pwa`.

رخصته **SIL OFL 1.1** — حرّة تجارياً وقابلة لإعادة التوزيع مع المنتج، ونصّها
في [`app/src/fonts/LICENSE.txt`](./app/src/fonts/LICENSE.txt). **أبقِ الملفّ**
فالرخصة تشترط مرافقته.
