# تطبيق مسجدي — واجهة الويب

واجهة عربية (RTL) لمسار التطوّع العيني، وهو المسار القابل للإطلاق في المرحلة
الأولى. تتحدّث مع دوال السحابة في `../cloud` عبر Parse JS SDK.

```bash
npm install
cp .env.example .env      # مفاتيح العميل — بلا Master Key
npm run dev
npm run build
```

## لماذا ويب لا React Native

المواصفة في `../docs/PROJECT_SPEC.md` تذكر React Native. هذه النسخة ويب لأنها
**قابلة للبناء والتجريب فعلياً** هنا: بُنيت وشُغّلت وقُيدت بمتصفّح حقيقي على
خادم Parse حقيقي. الفارق في الغلاف لا في المنطق — كل نداء في `src/api.js` هو
نفسه الذي سيستدعيه تطبيق React Native لاحقاً، فالانتقال يعيد استعمال الطبقة
كما هي.

## القواعد المحفوظة هنا

- **لا Master Key في أي ملف.** العميل يحمل `appId` و`javascriptKey` فقط.
- **كل كتابة عبر دوال السحابة.** لا `save()` على أي فئة في `src/api.js`؛
  القراءات المسموحة (`ServiceRequests`) وحدها استعلامات مباشرة.
- **رسائل الخطأ تُعرض كما تأتي** من `cloud/lib/errors.js` — عربية ومفهومة، لا
  نصّ Parse الإنجليزي.

## الشاشات

| الدور | الشاشات |
|---|---|
| إمام | مساجدي (وطلبات كل مسجد وتفاصيلها واختيار المتطوّع) · تسجيل مسجد · حسابي |
| متطوّع | الفرص المفتوحة · مهامّي واهتماماتي · حسابي |
| مشرف | اعتماد الشركات · حسابي |

## الخريطة

شاشة «حولي» تعرض المساجد على خريطة جوجل مضمّنة: علامة زرقاء لموقعك، وعلامة لكل
مسجد، والنقر عليها يفتح بطاقته وزرّ «هذا مسجدي». ومُبدِّل **خريطة / قمر صناعي**
— وهو أقرب ما يقابل «جوجل إيرث» داخل صفحة، إذ لا تملك Earth واجهة تضمين عامة.

**المفتاح اختياري ويخصّك.** أنشئه من Google Cloud Console (Maps JavaScript API)،
قيّده بنطاق موقعك، وضعه في `VITE_GOOGLE_MAPS_API_KEY`. وبدونه **لا يسقط شيء**:
تُخفى الخريطة وزرّ تبديلها، وتبقى القائمة بالمسافات مرتّبةً بالأقرب — وهي المسار
الافتراضي في المرحلة الأولى، فلا يتوقّف الإطلاق على حساب مدفوع لدى جوجل.

استُعملت JavaScript API لا Embed API لأن الثانية تعرض موقعاً واحداً، ونحن نعرض
عشرات المساجد بعلامة لكل واحد.

## ما ليس فيه بعد

- مراجعة طلبات ملكية المساجد من شاشة المشرف (تتم بـ`reviewMosqueClaim` مباشرة).
- العمل بلا إنترنت والتثبيت كتطبيق (PWA).
- مسار التبرعات كاملاً — معطّل حتى صدور تصريح الوزارة.
- رفع صور الإنجاز مع `markWorkDone`.
- لا يعمل بلا إنترنت ولا يُثبَّت كتطبيق (PWA) بعد.
