# لقطات العرض

أربعَ عشرةَ شاشة **من التطبيق وهو يعمل** — لا رسومَ تصميم ولا بياناتٍ مخترَعة.

التُقطت بتشغيل `parse-server` حقيقي فوق PostgreSQL، واستيراد مساجد وزارة
الأوقاف، ثم المشي في الرحلة كاملةً في متصفّح Chromium بمقاس هاتف (420×880).
والمسجد فيها حقيقيّ من `data/mosques.json`: جامع فرقة ذهبون — ثمريت، ظفار،
رقم الوزارة 60/48.

والترتيب هو ترتيب الوقوع لا ترتيب الشاشات:

| # | الملفّ | الشاشة | صاحبها |
|---|---|---|---|
| ١ | `01-login` | الدخول | الجميع |
| ٢ | `02-signup` | التسجيل — والشرط مقروءٌ قبل الضغطة | الجميع |
| ٣ | `03-imam-empty` | مساجدي قبل التسجيل على مسجد | القائم على المسجد |
| ٤ | `04-claim-search` | البحث في ١٨٬٢١٤ مسجداً | القائم على المسجد |
| ٥ | `05-admin-queue` | مراجعة الإشراف ومعها قرينةُ المسافة | الإدارة |
| ٦ | `06-imam-mosque` | مساجدي بعد الاعتماد | القائم على المسجد |
| ٧ | `07-requests` | الاحتياجات ووسمُ الاستعجال | القائم على المسجد |
| ٨ | `08-opportunities` | الفرص القريبة مرتَّبةً بالمسافة | متطوّع |
| ٩ | `09-around` | حولي — مساجد الحيّ ومسافاتها | متطوّع |
| ١٠ | `10-interest` | تسجيل الاهتمام | متطوّع |
| ١١ | `11-choose` | اختيار المنفّذ بالسمعة، ومعه بابُ الشركات | القائم على المسجد |
| ١٢ | `12-inbox` | الوارد — الدعوة تصل ومنها يُقال «يهمّني» | متطوّع |
| ١٣ | `13-trail` | سجلّ المسجد — بالصفة لا بالهوية | الجميع |
| ١٤ | `14-profile` | حسابي ونسبةُ المصدر | الجميع |

**ولإعادة توليدها** بعد تغييرٍ في الواجهة: تُلتقط بالمِرقاة نفسها التي تُشغّل
`npm run test:e2e` — خادمٌ حقيقي، وبناءُ الواجهة عليه، ثم المشي في الرحلة.
وليست جزءاً من `npm run verify`: هي عرضٌ لا حارس، والحُرّاس في `tests/e2e/`.
